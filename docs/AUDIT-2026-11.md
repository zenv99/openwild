## Why most of the world still has no photos

The photo job already walks regions one at a time, nearest Bali first, and already uses the bulk sources: GBIF media, research-grade iNaturalist, Wikimedia Commons, and Wikidata. It is not a species-by-species hand crawl. Two things were stopping it from covering a whole country:

1. A cap of 5,000 species per run, applied to the head of the list. When that head finished inside the time limit, the scheduler treated the country as done and never photographed species 5,001 onward. Thailand sitting at 4,470 photos out of 16,228 species is that cap.
2. The next run of a capped country would have collected the same head again, because a species with no usable photo was not marked attempted.

`select_photo_batch` now skips names already tried and takes the next batch. The pack build writes `walk-shardN.txt`. While that file says more species remain, the scheduler keeps doing a full pass instead of switching to a top-up of the same head. A finer pack waits until its country pack already has photos (California, Hawaii, and Alaska wait for the United States). Bali keeps its own runs.

This does not publish new photo bytes in this change. Filling the 59 names-only countries is the existing GitHub Actions job, one region at a time, a few hours per batch. Publishing all of them from this machine would repeat that queue and blow the same runner limits.

## App shape

Offline Android app (Kotlin, Jetpack Compose, CameraX, LiteRT). One model file in the app, `ow-dinov2s-384-v1`, 22 MB, input 224 and a 384-number fingerprint. Region packs are SQLite files downloaded from the GitHub release `packs`, checked by SHA-256, and only from `github.com` / `githubusercontent.com`. Explore and species pages read the pack on the phone. The network is for downloading a pack or the optional Better recognition model, and for a report or online check the person explicitly sends.

Photo identification compares the fingerprint with int8 prototypes in the pack (nearest prototype per species, several photos fused, a prior from how often the species is recorded and the month). Confidence thresholds live in `Confidence.kt` and were calibrated on Bali reference photos. Leave-one-out on Bali, from `data/regions/ID-BA/eval/ACCURACY.md`: 25,929 photos, 3,176 species, right plant first 49.7%, in the top 3 61.4%, in the top 10 72.0%. That is an upper bound on good labelled photos. This change does not retrain the model and does not claim a new field accuracy.

## Identifier: what was measured

On this machine, JVM, 6,000 prototypes, 384 dimensions, 3 photos, single threaded, median of 5 warmed runs:

| Dot loop inside the same search | Median |
|---|---:|
| Previous 4-wide | 8.3 ms |
| Tried 8-wide | 8.4 ms |

Top-1 was the same. The 8-wide loop was not kept. The search was already in the right shape (one pass, unrolled, parallel only past 2,048 prototypes).

What did change is scoring when two packs are on. A synthetic case with the same plant stored twice (Bali and Indonesia) plus a distractor, temperature 0.2:

| | Top probability |
|---|---:|
| Counted as two species | 0.488 |
| One species, best fingerprint kept | 0.953 |

Same unit test: one pack matches the existing identifier exactly (same top, tier, score, probability). Real photos were not re-scored; the model and the single-pack math are unchanged. Better recognition (the optional BioCLIP model) stays on the region Explore is showing, because those fingerprints are a different length and must not be mixed with the built-in ones.

## Home screen

Under Identify, the home screen lists:

- **Our brain.** The built-in model, its id, and its size. A switch turns photo identification on or off. Turn off confirms first. The file is inside the app, so turning it off does not shrink the install; turning the switch on uses it again. A downloaded Better recognition model, if one is stored, is removed by that action. With the brain off, the camera still opens, and Identify sends the person to search by name with a clear line.
- **Each region pack on the phone.** Name, version, size, species count, whether it can identify a photo. A switch includes it in Identify. The one Explore is showing is labelled. Delete asks first and removes the downloaded file only. The copy on GitHub is untouched. If the pack was only ever inside the app and was never copied out, the switch is how it is turned off.

Country first: GPS and the phone's country suggest the country pack. A point in Bali still resolves to Bali as the finer pack, and the home screen offers it as something to add. The old shortcut that treated the whole Asia/Makassar time zone as Bali is gone; that zone is also Sulawesi and Nusa Tenggara. Indonesia is the suggestion, Bali is the finer offer.

## Safety, licensing, offline

`SAFETY.md` is unchanged. The footer "Never eat anything based only on this app" is still on the home screen. Harms still come before benefits. This change does not add eating guidance or psychedelic guidance.

`content/evidence/pfaf_facts.csv` is present (16,276 lines). It is the existing Plants For A Future fact table, described in `DATA_SOURCES.md` as used with permission and not a copy of their pages. It was not removed and nothing new was fetched from pfaf.org or tropical.theferns.info. Whether to keep that file is Zen's decision.

iNaturalist CC BY-NC and CC BY-NC-SA photos are still allowed because `NONCOMMERCIAL_APP` is true. No-derivatives licences stay out. If OpenWild is ever sold or carries ads, that switch has to be turned off and packs rebuilt from commercial-ok photos only. That is also Zen's decision, not a silent change.
